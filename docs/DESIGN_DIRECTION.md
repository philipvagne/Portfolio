# DESIGN_DIRECTION.md

> This document defines the visual direction and design philosophy for all current and future portfolio, landing page and marketing website work.
>
> Every design decision should be evaluated against these principles before implementation.

1. Vision
Objective

Create a portfolio that immediately communicates craftsmanship, taste, and engineering quality through a calm, premium visual experience.

The portfolio should showcase software engineering projects while presenting them with the same care and attention that great product companies present their products.

The visitor should leave remembering the projects—not the interface.

2. Design Principles

Every design decision should support one or more of these principles.

Calm over flashy
Premium over trendy
Simple over clever
Spacious over crowded
Intentional over decorative
Products before technology
Show before explain

When uncertain, simplify.

4. Visual Language
Colors

Primary palette

White
Warm white
Soft grey
Charcoal
Black

Accent colors should primarily come from the products themselves.

Typography

Inspired by Linear.

Characteristics:

Clean
Modern
Restrained
Confident

Hierarchy should come from spacing and size rather than excessive font weight.

White Space

Generous spacing is preferred.

Every section should breathe.

Never add visual elements simply to fill empty space.

5. Homepage Structure

The homepage exists for one purpose:

Get visitors interested enough to open a project.

It is not the place to explain every architectural decision.

The homepage should:

Introduce who I am
Showcase my best work
Build trust
Encourage exploration

The detailed story belongs inside individual project pages.

6. Project Presentation

This is the highest priority section of the homepage.

Projects should be presented as products.

Each project should contain:

Premium image or mockup
Project title
One concise supporting sentence
Clear click interaction

Avoid traditional project cards with large blocks of text.

Images should carry the visual weight.

7. Navigation

Navigation should be:

Small
Elegant
Minimal
Quiet

It should support the page rather than dominate it.

8. Motion

Animations should be subtle.

Preferred:

Fade
Slight translate
Gentle scale

Avoid:

Large motion
Flashy transitions
Heavy animation
9. Do
Let images dominate
Use generous spacing
Reduce visual clutter
Prioritize hierarchy
Keep layouts simple
Make every section feel intentional
10. Don't
Generic developer portfolio aesthetics
Technology badges everywhere
Busy layouts
Heavy gradients
Glassmorphism
Oversized shadows
Explaining everything on the homepage
Decorative elements without purpose
11. Success Criteria

The redesign is successful if:

The homepage feels premium before any text is read.
The projects become the primary visual focus.
The portfolio feels cohesive from top to bottom.
The design reflects the same level of care as the products themselves.
Visitors want to click into the projects.
